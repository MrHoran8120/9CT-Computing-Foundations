# Lesson 2 guide: Taking control of your files

**Time:** 75 minutes. **Students need:** a charged laptop, their Lesson 1 folders if they have them, and the app open in its own tab.

**Goal:** students can save work where they choose, tell versions of a file apart using evidence, and find where a file is really stored. Some students hand in an old version of their work. This lesson builds the habits that prevent it. Lesson 3 covers ZIP files and handing in.

**Why Notepad and TextEdit:** they make students choose a name and a folder, and they show when there are unsaved changes, as VS Code does. Google Docs saves by itself and has no Save As, so it would skip the skill.

In the code, this lesson's ID is `L5`, because it was added after the others. Students see it as Lesson 2.

## Timing

| Minutes | Section | Students do |
|---|---|---|
| 5 | Find your Lesson 1 work | Find a file, its path and its extension, with no step-by-step help |
| 10 | Select several files | Move a block of photos, and copy two notes that aren't together |
| 13 | Save on purpose | Write, save to Year 9, close, reopen, then make a second version |
| 12 | Copies and versions | Prove the versions are separate, then pick the complete speech |
| 10 | Find missing work | Search for the excursion form, then open its folder |
| 25 | Recovery challenge | Organise the garden project, then check it against the checklist |

The recovery challenge gives goals, not clicks. Hold back from giving steps. Point students to the search box at the top of the app, or back to the section that taught the skill.

There are two extra challenges for fast finishers: shortcuts, and why the newest file isn't always the complete one. They don't count towards progress or the Dashboard.

## Where students may get stuck

- **No Lesson 1 work:** students on a new laptop make Documents › Year 9 and carry on. Nothing later depends on Lesson 1's files.
- **Shift-click on a Mac:** it selects a block reliably in list view. Check students have chosen **View › as List**.
- **Dragging moves everything selected:** if a student drags one file and the rest move too, they had several selected. Clicking an empty space clears a selection.
- **Saving somewhere unknown:** if a student can't find `my-plan.txt`, they probably saved without choosing a folder. Use search to find it, then **Open file location** or **Show in Enclosing Folder**. That's a good teaching moment.
- **TextEdit makes rich text:** if the file is `my-plan.rtf`, the student skipped **Format › Make Plain Text**. It still works for the lesson.
- **TextEdit saves by itself:** once a file has a name, TextEdit usually saves changes automatically. That's why the Mac steps use **Duplicate** before changing anything. If a Mac student changes the archived report by mistake, they can get a fresh copy by downloading the ZIP again.
- **Notepad remembers unsaved text:** newer Notepad can restore unsaved text when reopened. It still isn't in the file, which matters when the file is attached or uploaded.
- **Search on a Mac:** students must click **Practice files** next to **Search**, or Finder searches the whole Mac.

**Versions prediction:** `my-plan.txt` stays the same.

A finished project has the images together, all three original reports unchanged in **Archive**, and one new report outside it. The new report has a clear name, all five parts, and a `Checked by:` line. Students should be able to say that they chose the report by its contents.

**Shortcut on a USB drive:** it doesn't open the essay, because the essay is still on the laptop.

**Newest date:** the old draft, because saving gives it a new date. Before handing in, open the file and check it against the task.
