# Lesson 1 guide: Computer fundamentals

**Time:** 75 minutes. **Students need:** a charged laptop, and the app open in its own tab, beside File Explorer or Finder if the screen is big enough.

**Goal:** students can find and manage their own files, and can explain where a file is stored.

Fast finishers can choose from six extra challenges, in any order. They don't count towards progress or the Dashboard, and each takes about 5 to 10 minutes.

| Extra challenge | What students do |
|---|---|
| Path puzzles | Read and predict paths. |
| Break a file on purpose | Rename a copy of a text file to `.jpg`, see it fail, then fix it. |

| Find files fast | Sort a fresh copy of Sam's files by size and date, and search by extension. |

If you run short of time, finish the rescue challenge next lesson rather than rushing it, because it's where the skills come together.

## Where students may get stuck

- **Opening apps on a Mac:** students learn both the Dock and Spotlight (Command + Space). If Spotlight does nothing, check they're holding Command rather than Control or Option.
- **Downloads go somewhere else:** the browser may ask where to save a file, or add a number when a file is downloaded twice.
- **OneDrive in a Windows path:** many Windows laptops save Documents to OneDrive, so the path includes `OneDrive`. It's a useful real example for the local and cloud section.
- **The Mac move shortcut:** students copy first, then press Option + Command + V at the destination.
- **Hidden extensions:** most computers hide extensions by default, so students turn them on in section 2, before their first download. Check that everyone has done this, because later steps rely on it. If a name becomes `sunset.jpg.jpg`, the student probably skipped it.
- **Word files on a Mac:** if there's no app for `.docx`, students can select the file and press the space bar to preview it.
- **Working inside the ZIP:** on Windows, opening a ZIP without extracting it looks like a normal folder, but changes don't stay. Check that the `Sams files` folder is in Documents › Year 9. Lesson 2 explains why.

## Answers

**Apps or files:** Chrome, Word, Calculator and Spotify are apps. The others are files.

**Correct path:** `Documents`, then `English`, then `poem.docx`.

**Extensions:** `.docx` Word document, `.pdf` PDF document, `.jpg` photo, `.mp3` music, `.html` web page, `.zip` compressed folder.

**Laptop stops working:** only the science report in Google Drive survives.

**Path puzzles:** a folder called `Volcanoes`, the path ending `Year 9\Science\map.png`, and "they are in different folders".

**Break a file on purpose:** the name said photo, but what was inside was still text. To make a PDF, use Save As or Export in Word.

**One naming rule:** `2027-03-history.txt` sorts in date order. Students' rules will differ. Check that a rule covers all 15 files and shows which version is newer.

**Find files fast:** the largest is `logo-new.png` (about 12 KB), the most recent is `assignment final FINAL v2.docx`, and there are 4 PDFs. The 900 KB and 12 MB files fit in an email, while the 30 MB and 2 GB files don't. These answers need a fresh copy of the ZIP, because opening and saving a file changes its date.

**One file, two versions:** the new paragraph isn't in the cloud copy while the laptop is offline. There are then two different versions, so students should open and compare both before removing either.

**One file, two apps:** nothing changes in the file. A friend can read a `.docx` in another app that understands it, such as Google Docs.

There isn't one right structure. Look for these when students show you their work:

- Every file is in a folder, and the folders follow one clear idea.
- File names say what each file is, and the extensions are unchanged.
- They can explain their choice about the two versions of the English assignment.
- Their two sentences explain why, not just what.
